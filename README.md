# 哈工程秋招雷达

把哈工程就业网公开的宣讲会、双选会汇总成一个可离线打开的单文件页面。

## 使用

小红书企业作息/薪资/体验调研：双击 `open-xhs-research.bat`，粘贴搜索请求cURL后点“导入并继续查询”。每次更换登录信息会保留进度。详细规则与评分入口见 [小红书调研说明](XHS_RESEARCH.md)。此入口只在本机处理登录信息。

手动更新：双击 `refresh.bat`，脚本会执行增量同步并打开 `index.html`。页面中的“增量更新”按钮会打开同一套手动入口说明。

自动更新：运行一次 `schedule_daily_update.ps1`，会注册 Windows 任务“HRBEU Job Radar - Daily Incremental Update”，每天 02:15（本机时间）执行 `update-latest.bat`。更新日志写入 `logs/latest-update.log`。

云端自动更新：按 [GitHub Pages 发布说明](DEPLOY_GITHUB_PAGES.md) 上传到 GitHub。项目已包含 `.github/workflows/publish-pages.yml`，发布完成后手机访问固定网址；每天北京时间约 02:15 自动抓取并发布，也可以在 GitHub Actions 中手动更新。

命令行：

```powershell
python -X utf8 .\scrape_hrbeu.py

# 强制重新处理全部记录（模型或规则大改后使用）
python -X utf8 .\scrape_hrbeu.py --full-refresh
```

可选参数：

```powershell
# 从指定日期开始
python -X utf8 .\scrape_hrbeu.py --since 2026-09-01

# 包含全部历史活动
python -X utf8 .\scrape_hrbeu.py --include-past
```

## 数据口径

- 活动、时间、校内地点来自哈工程就业网公开列表接口。
- 学校详情页可能要求登录；页面保留原始详情链接，不尝试绕过登录。
- “城市”优先取活动/企业名称中的城市线索，其次使用总部或主要基地推断；这不等于岗位工作地点。
- 城市、活动类型和行业方向筛选框支持勾选多项；不勾选表示“全部”。
- 网络补全的城市会显示“网络资料（待核验）”，详情中的“城市网络来源”可打开对应检索页。集团活动和全国性招聘会标记为“多地”，不强行归到总部城市。
- “个人适配”按两份简历拆成“IC 设计验证”和“AI 应用开发”两条方向，综合视图取两条中较高分；它是可解释的初筛分，不是录用概率。目标城市、补充关键词和组织偏好可以在页面左侧修改，配置仅保存在浏览器本地。
- 薪资字段优先解析学校公开接口/详情中出现的薪资；学校未公开时实际检索公开招聘来源。找到岗位样本就标注“网络查询得到”并保留来源，没找到则显示“网络查询未找到公开薪资”并提供检索入口。不会把不对应岗位或城市的网上样本冒充确定薪资。
- 更新机制默认是增量处理：仍需读取学校公开分页列表（接口未提供公开的 `updated_since` 游标），但会用 `data/raw-events.json` 和 `data/normalized-events.json` 复用未变化记录，只重新标准化新增、变化或模型版本更新的记录。
- `data/events.json` 始终是当前完整活动列表，不是差分列表；增量更新不会改变页面展示口径。
- “企业口碑”对少量高相关企业加入了公开材料和社区讨论入口；其余使用行业级核验清单，不生成虚假评分。

请控制刷新频率，脚本已设置分页间隔和失败重试。
